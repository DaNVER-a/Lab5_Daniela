## Мета

Налаштувати C++-проєкт із бібліотекою SFML, системою CMake та пакетним менеджером vcpkg і реалізувати графічне чисельне моделювання фізичного процесу.

## Математична модель

- Рівняння руху математичного маятника: `θ'' = −(g/L)·sin θ`, де `g=9,81 м/с²`.
- Система записана як `θ' = ω`, `ω' = −(g/L)·sin θ`.
- Чисельне інтегрування: **метод Рунге—Кутти 4-го порядку (RK4)** з `dt = 1/240` с.
- Для малих кутів теоретичний період: `T≈2π√(L/g)`; для великих кутів результат нелінійної моделі довший за цей наближений період.

## Керування

| Клавіші | Дія |
|---|---|
| ↑ / ↓ | Довжина підвісу +/− 0,10 м |
| → / ← | Початковий кут +/− 5° |
| P | Пауза/продовжити |
| R | Перезапустити модель |
| Esc | Закрити програму |

Показники відображаються в графічному вікні, а за відсутності системного шрифту — в заголовку. Програма використовує стандартний шрифт Windows за наявності; жоден файл шрифту в репозиторій не включено.

## Підготовка у Visual Studio

1. Розпакувати проєкт у `C:\Users\stsdu\source\repos\Lab5_Daniela`.
2. Відкрити **Visual Studio → File → Open → Folder** і вибрати папку `Lab5_Daniela`.
3. Дочекатися завершення CMake-конфігурації через `default` preset. Залежність SFML має встановитися автоматично через vcpkg. Для конфігурації використовуються Visual Studio 18 Insiders і `x64-windows`.
4. Якщо є помилки після першої конфігурації: **Project → Delete Cache and Reconfigure**.
5. Натиснути **Build → Build All**.
6. Вибрати `Lab5_Daniela.exe` біля кнопки запуску й натиснути **Ctrl+F5**.
7. Для експериментів окремо запустити `Lab5_Daniela_Experiments.exe` (створить `experiment_results.csv` у поточному робочому каталозі).
8. Окремо запустити `Lab5_Daniela_Tests.exe` і перевірити `PASS`.

> Увага: не запускайте `.exe`, доки не завершилася збірка. Якщо встановлена інша Visual Studio, виправте `CMAKE_TOOLCHAIN_FILE` у `CMakePresets.json`, вказавши актуальний шлях до `vcpkg.cmake`.

## Експеримент

Довжини підвісу 0,6 / 1,0 / 1,5 / 2,0 м; початкові кути 15° і 45°. Порівнюємо чисельно виміряний період зі шкільним наближенням T=2π√(L/g).

`example_results.csv` містить контрольний результат, отриманий компіляцією чисельної моделі. Для звіту краще використовувати власний запуск файлу `Lab5_Daniela_Experiments.exe`.
